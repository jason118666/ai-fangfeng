# ai-fangfeng

只做两件事：**检查**（只读）和**按清单配置**（可改，但必须逐项确认）。

## 第一步：先问清楚做哪个

- “帮我检查” → 走检查模式，**不要改任何东西**
- “新电脑帮我配” → 走配置模式

## 检查模式

1. 运行 `pwsh ./scripts/check.ps1`（Windows）。脚本只读，不输出密钥/订阅/节点。
2. 把输出**原样简短**转述给用户：通过了哪些、还有几项、每项怎么改。不要长篇解释。
3. 用户问“为什么”时，再按 `docs/机场版.md` 的“5 个坑”讲一条即可，别一次全倒出来。
4. 出现「无法判断」时，告诉用户缺什么证据：
   - 链路读不到 → 需要打开外部控制（仅 `127.0.0.1:9097`）或给一张「代理」页截图
   - 出口读不到 → 确认 Clash 在运行、端口正确

## 配置模式

先跑一次 `check.ps1` 看清现状，然后**严格按 `docs/改配置指南.md`** 逐项处理：每项怎么探测、怎么改、怎么验证、怎么回滚都写在那里。

要点：
- 一次只改一项，改完立刻验证；不过就回滚这一项，别接着改
- 改文件前先备份，并告诉用户备份路径
- TUN、系统代理这类需要点界面的，让用户点，不要替他改注册表
- 改完重跑 `check.ps1`，把“改前 / 改后”简短对比给用户

## 硬性规则

- **不要靠组名判断**。机场不同、自建不同，组名全变。只看 `check.ps1` 的行为探测结果（真实访问 + 链路）。
- **不要输出**订阅地址、节点密码、订阅链接、账号信息。
- **不要开外部控制给外网**，只允许 `127.0.0.1`。
- 端口必须全链路一致：Clash 监听端口 = 系统代理端口 = `HTTPS_PROXY` 端口。
- 兜底规则插在 `MATCH` **前面**，不能放最前面（会抢掉广告拦截）。
- 断线兜底只认结果：Clash 关掉后 Claude Code 必须连不上，而不是连上真实宽带。

## 自建版

用户说要自己搭 VPS 时，读 `docs/自建版.md`。服务器操作前必须让用户确认每一步，密码由用户自己在终端输入，不要出现在对话里。
