# 自建版

自己买 VPS 搭一条私人线路。适合：想让一个 IP 只给自己几个号用、不想跟陌生人共享机场 IP。

比机场版多做的事只有三件：买服务器、装面板、把规则放到自己服务器上。本地的那 8 项配置和机场版**完全一样**。

网页版 Claude 如需专用登录环境，可选配合 [AdsPower 指纹浏览器](指纹浏览器.md)，仍需完成本地网络配置。

## 一、准备

- 一台海外 VPS（Ubuntu 24.04），记下 IP、root 密码、SSH 端口
- 一个域名（可选，想用 TLS 节点才需要）
- 本地装好 Clash Verge Rev

## 二、服务器

1. **3x-ui** 面板：装好后建两个节点，一个 REALITY、一个 TLS，作为主备。
2. **Clash 订阅模板**：用 `templates/clash-template.yaml`，替换 `{{SERVER_IP}}`、`{{REALITY_NAME}}`、`{{TLS_NAME}}`，写进 3x-ui 的订阅规则。
3. **规则镜像**：把下面这些上游每天拉到本机，客户端从你自己的服务器下载（不依赖 GitHub 能不能打开）。

## 三、规则从哪来

| 来源 | 内容 |
|---|---|
| `MetaCubeX/meta-rules-dat` | `geosite/openai.yaml`、`anthropic.yaml`、`google.yaml`、`youtube.yaml`、`cn.yaml`；`category-ai-!cn.mrs`；`geoip/cn.mrs`；`geoip.metadb`、`GeoLite2-ASN.mmdb` |
| `ACL4SSR/ACL4SSR` | LocalAreaNetwork、UnBan、GoogleFCM、GoogleCN、YouTube、Netflix、ProxyMedia、Telegram、Apple、Microsoft、OneDrive、ProxyGFW、ChinaDomain、ChinaCompanyIp、ChinaIp、Download |
| `misakaio/chnroutes2` | 中国 IP 段（转成 `ipcidr`） |
| 本项目 | `templates/rules/direct-lite.yaml`（QQ/淘宝/B站/抖音/京东/知乎…直连） |

**要点**：
- 每天定时刷新，下载失败保留旧文件，不要推空规则。
- 客户端只从自己服务器拉，规则更新不看你本地网络能不能连 GitHub。
- 大列表用 `rule-providers` + `mrs`，不要塞进 rules 里。

## 四、规则顺序（照抄这个骨架）

```
内网/回环 → IP-CIDR,你的服务器IP/32,DIRECT
→ AI 域名（claude / openai / anthropic / gemini / ai-non-cn）→ AI 组
→ 国外分类（YouTube / Netflix / Telegram / Google / Media）
→ 国内域名库 → 国内 IP 库 → GEOIP,CN → DIRECT
→ MATCH 兜底
```

**和机场版最大的区别**：组名是你自己定的，可以固定；但仍然建议用检查器的行为探测，而不是靠名字。

## 五、一个 IP 怎么用才稳

- 一个 IP 只挂 2～3 个号，不要更多。
- 不租、不共享、不借人。
- 一个号固定一台设备 + 一个出口 IP，别来回切。
- IP 被标记就换 IP（多数商家支持换 IP 或退掉重买）。

## 六、上线前验收

```powershell
pwsh ./scripts/check.ps1
```

再手动确认三件事：
1. 浏览器打开 `https://ip.net.coffee/claude/`，出口是你服务器的 IP，信任评分 ≥ 70；
2. DNS 出口不在中国；
3. WebRTC 的 UDP 出口也是你服务器的 IP。
