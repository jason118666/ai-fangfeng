# 机场版

买了机场订阅，用 Clash Verge Rev。目标：本地不漏 IP。

网页版 Claude 如需专用登录环境，可选配合 [AdsPower 指纹浏览器](指纹浏览器.md)，仍需完成下面的网络配置。

## 要配的 8 件事

| # | 位置 | 配成什么 |
|---|---|---|
| 1 | 首页 | 模式 = 规则 |
| 2 | 首页 | TUN 开；系统代理也开（Clash 挂了浏览器就没网，而不是裸连） |
| 3 | TUN 齿轮 | 严格路由开、自动路由开、自动选出口网卡开、DNS 劫持 `any:53`、MTU 1500、堆栈 GVisor |
| 4 | 端口 | 所有代理工具统一一个端口（例如 7892），环境变量和系统代理都指这个 |
| 5 | 全局扩展 Merge | 只放兜底关键词规则（claude / anthropic / openai） |
| 6 | DNS 覆写 | 开、勾选「遵循路由规则」；域名服务器用 CF/Google DoH；直连域名服务器填 `https://doh.pub/dns-query` |
| 7 | 环境变量 | `HTTPS_PROXY=http://127.0.0.1:7892`、`NO_PROXY=localhost,127.0.0.1,::1` |
| 8 | Windows | 时区 = 出口所在地；定位授权 = 拒绝；Chrome/Edge 设 `WebRtcIPHandlingPolicy=disable_non_proxied_udp` |

## 换机场时最容易踩的 5 个坑

1. **组名不是固定的**。`🧲 海外AI`、`AI-人工智能`、`🚀 节点选择` 都可能是同一作用。判断标准是“claude.ai 实际走的链路”，不是名字。
2. **国内站直连靠两条**：域名库 `GEOSITE,cn` + IP 库 `GEOIP,CN`。只写 GEOIP 时，豆包/deepseek/npmmirror 这类解析到海外 CDN 的国内服务会漏到代理。
3. **MATCH 是兜底**。它指向谁，没命中任何规则的流量就去哪。指向代理组是常规做法，但要知道有这回事。
4. **AI 组里带 DIRECT 是隐患**。误点一下，AI 流量就直连了。检查器会单独提示。
5. **断线会漏**。机场客户端没配环境变量时，Clash 一退，Claude Code 会直接走真实宽带。配了 `HTTPS_PROXY` 就是“连不上”，而不是“裸连”。

## 怎么自查

```powershell
pwsh ./scripts/check.ps1
```

输出只有三块：通过的、要处理的、结论。要处理的每项都写了去哪改。

## 规则从哪来

机场版的规则由机场下发，你改不了，只能看它有没有覆盖 AI 域名。检查器用真实访问来判断：

- 访问 claude.ai，看链路是不是 DIRECT
- 访问国内检测点，看是不是走本地
- 看 AI 组里有没有 DIRECT

如果你想让国内直连更稳，在 `Script.js` 里加两条兜底（见 `templates/Script.js`），插在 `MATCH` 前面，不要放最前面，否则会抢掉广告拦截。
