# 改配置指南（给 AI 看的）

本项目**不提供自动修脚本**。原因：机场不同、组名不同、端口不同、Clash 版本不同，写死的脚本一定会改错。
正确做法：**AI 先跑 `check.ps1` 看清这台机器的实际情况，再逐项决定怎么改。**

## 五条硬规矩

1. **先探测，再动手**。不探测就改 = 赌。探测不到就跳过，不要猜。
2. **一次只改一项**，改完立刻验证。验证不过就回滚这一项，**不要接着改下一项**。
3. 改任何文件前先备份，并告诉用户备份在哪。
4. 用户没点头的项不要改；说“帮我检查”时**一项都不许改**。
5. 不在对话里输出：订阅地址、节点密码、账号、密钥。

## 每项怎么改

| 项 | 探测方法 | 改法 | 怎么验证 | 回滚 |
|---|---|---|---|---|
| 端口统一 | 读 `mixed-port`；系统代理端口；`HTTPS_PROXY` 端口；实际监听端口 | 选定一个端口，把 Clash（`verge.yaml` 的 `verge_mixed_port`）、系统代理、环境变量改成同一个；改完重启 Clash | `check.ps1` 端口一致性通过 | 恢复 `verge.yaml` + 环境变量 |
| TUN 与严格路由 | `/configs` 或 `clash-verge.yaml` 的 `tun` 段 | 优先让用户在首页/TUN 齿轮里点（AI 点不了 UI）；必要时改 `verge.yaml` 的 `enable_tun_mode` 后重启 | `tun.enable=true`、`strict-route=true`、Mihomo 网卡 Up | 改回原值重启 |
| 国内直连兜底 | 访问国内检测点，看返回是不是真实 IP | 在 `profiles\Script.js` 里，把 `GEOSITE,cn` / `GEOIP,CN` 插到 `MATCH` **前面**（模板见 `templates/Script.js`） | `check.ps1` 国内直连通过；`check.ps1` 显示的两条兜底在 MATCH 之前 | 恢复备份的 `Script.js` |
| DNS 覆写 | 读 dns 段：`enable`、`respect-rules`、`nameserver`、`direct-nameserver` | UI 里开 DNS 覆写、勾选遵循路由规则、填 DoH（模板 `templates/dns_config.yaml`）；或改 `dns_config.yaml` 后重启 | 四项都有值，`check.ps1` DNS 项通过 | 恢复 `dns_config.yaml` |
| 客户端兜底 | 读用户级 `HTTPS_PROXY`、`.codex\.env` | `[Environment]::SetEnvironmentVariable('HTTPS_PROXY','http://127.0.0.1:<端口>','User')`，同时设 `NO_PROXY` | 新开终端里 `$env:HTTPS_PROXY` 正确；关掉 Clash 后 `curl` 报连接失败（不是裸连） | 删掉这两个变量 |
| 系统代理 | 读 `ProxyEnable` / `ProxyServer` | **让用户在 Clash 首页点**（自动写注册表），不要手改注册表 | `ProxyEnable=1` 且端口等于 Clash 端口 | 用户在首页关掉 |
| 时区 / 定位 | `Get-TimeZone`；`ConsentStore\location` | 时区用 `Set-TimeZone`；定位改注册表 `Deny` | `check.ps1` 时区一致性 + 定位两项通过 | 改回原时区 / 原值 |
| 浏览器 WebRTC | 读 `WebRtcIPHandlingPolicy`（Chrome / Edge） | 写 HKLM 策略 `disable_non_proxied_udp`，需要管理员 | `check.ps1` WebRTC 项通过；重启浏览器后生效 | 删除该策略值 |

## 怎么算“改好了”

不是看文件写进去了，而是跑一遍：

```powershell
pwsh ./scripts/check.ps1
```

再手动确认两点：
1. `claude.ai` 出口不是中国 IP，也不是 DIRECT；
2. 关掉 Clash 后，Claude Code 发消息失败（正常），不会偷偷走真实宽带。

## 什么时候必须停下来问人

- 探测结果互相矛盾（比如配置写 7892，实际监听 7897）
- 需要改订阅、换节点、动机场的规则文件
- 需要开外部控制且不是 `127.0.0.1`
- 需要用户点界面（TUN、系统代理）
- 任何一步验证失败

## 不做的事

- 不写“一键修复”脚本
- 不批量替换规则文件
- 不在没备份的情况下改 `Script.js`
- 不为了“看起来通过”去改检查器的判断
